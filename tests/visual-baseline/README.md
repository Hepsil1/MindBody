# Cross-device visual baseline

Screenshots of mindbody-sportwear.com across the device matrix the app actually
ships to. Generated by `npm run visual-snapshot`.

Devices (7) — chosen for engine + viewport + market-share coverage:

**WebKit family (Safari iOS):**

- **iphone-14** — 390×664 DPR 3 — most common 2023-2024 iPhone
- **iphone-8** — 375×667 DPR 2 — legacy iPhone (no notch / no safe-area), still common UA market
- **iphone-se** — 320×568 DPR 2 — narrowest viable iPhone, catches horizontal-overflow bugs
- **ipad-mini** — 768×1024 DPR 2 — tablet portrait, sits exactly at our `max-width:768px` breakpoint edge

**Chromium family (Android Chrome / Samsung Internet / Yandex / Mi / Opera — same engine):**

- **galaxy-s24** — 360×780 DPR 3 — actual Samsung viewport (Samsung is most-common Android in UA)
- **pixel-7** — 412×839 DPR 2.625 — vanilla Google Android Chrome

**Desktop:**

- **desktop** — 1280×720 — sanity check, no mobile @media applies

Coverage: ~96% of real-world engines + ~92% of real viewports (320-1280).
Remaining ~4-8%: HarmonyOS WebView (Huawei), Yandex-specific UA-sniffing,
old iOS — escalate to BrowserStack trial when needed.

Pages (5): home, shop-yoga, auth, pdp, checkout.

Why WebKit specifically: Playwright's webkit engine is the same WebKit
Safari uses on iPhone — same default CSS behaviours. This catches bugs
that Chromium-with-iOS-user-agent emulation misses (the cleanest example
in our history: `.header__burger span` empty `<span>` rendered 0×0 on
real Safari WebKit but 44×2 in Chromium emulation — three burger lines
were invisible on real iPhone Safari for a release).

Screenshots are `.gitignore`d by default — they're a local-run artifact.
If you want to track a frozen baseline (e.g. for visual regression), edit
`.gitignore` here to whitelist a snapshot.

## Commands

```bash
npm run visual-snapshot           # prod (mindbody-sportwear.com)
npm run visual-snapshot:local     # dev (localhost:3001 — autostarts via Playwright)
node scripts/visual-snapshot.mjs --device=iphone-14   # single device
```

After re-running, view individual screenshots in your editor or via
File Explorer at `tests/visual-baseline/<device>/<page>.png`.
